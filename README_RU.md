# Конвейер анализа рынка труда

## Обзор

Конвейер анализа рынка труда — это проект DE, ориентированный на сбор, обработку и анализ объявлений о вакансиях для инженеров данных.

Проект извлекает данные о вакансиях из общедоступных API, сохраняет необработанные ответы, нормализует поля вакансий, извлекает технические навыки и подготавливает данные для дальнейшего анализа.

## Цели проекта

Основные цели этого проекта:

- сбор вакансий из общедоступных источников
- хранение необработанных данных о вакансиях
- нормализация полей вакансий в структурированный формат
- извлечение технических навыков из вакансий
- анализ спроса на навыки, инструменты, страны и удаленные вакансии в области инженерии данных
- создание готового конвейера обработки данных

## Текущие возможности

- Извлечение вакансий из API Arbeitnow
- Сохранение необработанных ответов API в виде JSON-файлов
- Нормализация данных о вакансиях в DataFrame pandas
- Обработка пропущенных и пустых значений
- Извлечение технических навыков из заголовка, тегов и описания
- Сохранение обработанных данных в формате CSV

## Как запустить

Создание и активация виртуального окружения:

    uv venv
    source .venv/bin/activate

Установка зависимостей:

    uv pip install -r requirements.txt

Создание локального файла окружения:

    cp .env.example .env

Запуск экстрактора:

    python src/extractors/arbeitnow.py

## Вывод

Необработанные ответы API сохраняются в:

Обработанные наборы данных сохраняются в:
